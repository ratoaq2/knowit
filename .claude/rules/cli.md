# CLI options

`docs/usage.md` shows the `knowit --help` output. "Main options" in `README.md` lists the common options.
When you add, remove, or rename an option, or change its help text, update both files in the same commit.
Take the `--help` output from the Docker image, so that the first line is `usage: knowit`.
